# JavaScript ES6 Practice

This repository documents my practice while moving from JavaScript fundamentals into ES6.

Instead of learning each feature in isolation, I used small problem-solving exercises to understand where these features actually become useful.

## What I Practiced

### ES6 Fundamentals
- Arrow functions
- Default parameters
- Template literals
- Destructuring
- Spread operator
- Rest parameters
- Optional chaining
- Object methods
- `for...of`
- `for...in`

### Array & Data Processing
- `map()`
- `filter()`
- `find()`
- `reduce()`
- `sort()`
- Method chaining

### Deeper Concepts
- Closures
- Reference vs value
- Immutability
- Object/array copying
- Callback functions
- Strict equality
- Combining multiple concepts

## Structure

The practice is organized into five sections based on how I worked through the problems:

- `01-fundamentals`
- `02-problem-solving-01`
- `03-problem-solving-02`
- `04-practical-problems-01`
- `05-practical-problems-02`
